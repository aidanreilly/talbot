# Wavetables

The three banks in this directory are the ROM wavetable banks included with the open source [Synthesis Technology WaveEdit](https://synthtech.com/waveedit/) wavetable editor tool.

Each file holds 64 single-cycle waveforms of 256 samples, stored
end-to-end as mono 16-bit 44.1 kHz WAV, which is the standard WaveEdit
bank format.

| File | Bank |
| --- | --- |
| `rom_a.wav` | ROM A |
| `rom_b.wav` | ROM B |
| `rom_c.wav` | ROM C |
